What each mode is based on

Math CAPTCHA

Early text CAPTCHAs often asked something like "what is 7 + 15?" because a bot has to both read the warped characters and understand them. Here the problem is distorted the same way as the main test. Answers are plain numbers with no spaces. Subtraction never goes below zero, and the three-term problems appear once you have a few solves.

Color CAPTCHA

This mode borrows from the Stroop effect: reading a word is automatic, so naming a conflicting color slows you down. The word never matches its ink. After five solves the button order shuffles, so you cannot rely on position. Because it depends on telling colors apart, skip it if that is difficult for you; the Math and Grid modes need no color vision.

Grid CAPTCHA

reCAPTCHA's "select all squares with..." test uses photos. This version uses characters instead: each round names a class (digits, UPPERCASE letters, lowercase letters or symbols), and between two and four of the nine tiles belong to it. A wrong verify clears your selection but keeps the board, so you can correct it at the cost of accuracy.

Getting better

  • Accuracy matters more than speed in all three modes. A miss costs you a full attempt.
  • In Grid, scan for the odd class first and select as you go; press Enter to verify.
  • In Math, type the answer and press Enter without touching the mouse.
